---update_repo_on_flash--- 
Этот скрипт автоматически проходит по папкам рядом с собой, ищет Git-репозитории и выполняет `git pull`.
Он нужен для массового обновления проектов, например на флешке или общем диске с кучей репозиториев.

Что делает:
* определяет папку, где лежит сам скрипт
* отдельно обрабатывает специальные каталоги:
  * `Python`
  * `Obsidian`
* если папка сама является Git-репозиторием (`.git` внутри) → обновляет её напрямую
* если внутри папки есть несколько репозиториев → обновляет каждый
* для папки `Python` обновляет только проекты, начинающиеся на:
  * `0`
  * `1`
  * `2`
  * `3`

Пример структуры:

```text
flash/
├── update_repo_on_flash.sh
├── dotfiles
├── Python/
│   ├── 0_test/
│   ├── 1_parser/
│   └── temp_project/   ← пропустится
├── Obsidian/
│   ├── vault1/
│   └── vault2/
```

Как работать:
1. Положить скрипт в f:\My_Work\, где находятся папки с репозиториями.
